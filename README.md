# 豆瓣电影查询插件

AstrBot 豆瓣电影查询插件，支持搜索电影、查看详情和热门评论。

## 功能特点

- 🔍 电影搜索：支持关键词搜索电影
- 🎬 详情查看：展示电影详细信息，包括评分、导演、演员、简介等
- 📝 热门评论：自动获取并展示电影热门评论
- 📺 支持电视剧查询：自动识别电影和电视剧类型

## 使用方法

### 命令格式

```
/豆瓣 电影名/ID   - 搜索并查看电影详情
/豆瓣评论 电影名/ID - 单独查看电影评论
/豆瓣帮助        - 查看帮助信息
```

### 示例

```
/豆瓣 流浪地球
/豆瓣 1724604
/豆瓣评论 流浪地球
```

## 功能说明

1. **搜索结果选择**：当搜索到多个结果时，会显示列表，回复数字序号查看对应详情
2. **合并消息展示**：电影详情和评论会以合并转发消息形式展示，内容更整洁
3. **自动缓存**：搜索结果会缓存60秒，方便用户快速选择
4. **错误处理**：网络请求失败时会自动降级，保证基础功能可用

## 配置说明

插件无需额外配置即可使用。可以通过配置文件调整以下参数：

- `timeout`：请求超时时间（秒），默认30秒
- `max_results`：搜索结果最大显示数量，默认20条
- `timeout_seconds`：搜索结果缓存有效期（秒），默认60秒

## 依赖要求

- requests
- python 3.8+
